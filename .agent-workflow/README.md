# Private Agent Workflow Ledger

This directory is intentionally gitignored. It is the local source of truth for multi-agent Hermes work before a branch is pushed to Peter's fork or opened as an upstream PR.

Tracked here:
- branch records
- local issue/task records
- external-agent review reports
- PR handoff summaries

Do not put API keys or secrets here. Treat it as private project metadata, not a secret store.
